## Platform

All products are built on a shared platform — one login, one account, one LifeScore.

- **Auth:** Zitadel (self-hosted OIDC/SAML)
- **Stack:** Next.js 15 · TypeScript · PostgreSQL · Drizzle ORM · shadcn-style design system (`@vedastra/design-system`)
- **AI:** Multi-provider via Astra (Gemini · Groq · Claude · GPT-4)
- **Mobile:** LifeOS React Native app (single app for all B2C products)
- **Infra:** Hetzner Cloud (MVP) → AWS Lightsail Mumbai · Cloudflare · Docker
