# Security Policy — Vedastra Labs

> Org-wide Security Policy for the `Vedastra-Labs` organisation. GitHub surfaces this
> across all org repos that lack their own `SECURITY.md`. The **canonical policy** is
> `docs/SECURITY.md` in the platform docs repo — this is a pointer, not a restatement
> (Never Explain Twice — DOCUMENTATION-STANDARDS §3).

**Do NOT create a public GitHub issue for security vulnerabilities.**

Report responsibly to **security@vedastra.app** with: description, steps to reproduce,
potential impact, and any suggested fix.

Response SLA, supported versions, and full scope are defined in the canonical policy:
**`docs` repo → `SECURITY.md`** (https://github.com/Vedastra-Labs/docs/blob/main/SECURITY.md).

Scope covers all software under the `Vedastra-Labs` GitHub organisation.
